# PwA 1.4.2 发布说明

发布日期：2026-10-31

发布前最后一轮清理（玩法不变）：

## 隐私 / 敏感信息

- Release 编译不再带 PDB 路径：DLL 里不再出现 `D:\workspace\...` 这类本机路径（`<DebugType>none</DebugType>`）；
- 启动脚本 `start-coop.ps1` 不再写死本机 Steam 库路径：按 `PWA_GAME_ROOT` → Steam 注册表 → 默认路径自动找；
- 文档/示例里的本机路径改成 `…\Steam\...` / `<发布包目录>`；
- README、LICENSE、ENV_PROMPT 里不再带个人昵称；
- 世界包与 Mod 包都扫过：无 token、无本机用户名、无 IP。

## 文档

- README 写明验证范围：单机、本机双人、本机三人、带工坊 Mod 均 ✅；**远程真人玩家 ❌ 未验证**（目前确实没有真实的第三方玩家参与测试，只验证了 TCP 连通、口令校验、中继注册）；
- README 写明运行成本：agent 用 **DeepSeek v4.1 flash 1017** 时约 **¥3 / 小时**（按调用量浮动）。

## 产物

- npm：`cortico-world-pwa@1.4.2`（公开）；
- GitHub：`PwABridge-1.4.2.zip`、`cortico-world-pwa-1.4.2.zip`；
- Steam 上传：`release/PwABridge-1.4.2-steam.zip`（内部只有 `PwABridge/`），以及解压好的 `release/PwABridge-1.4.2-steam/PwABridge/`。

## Steam 上传

用 Steamworks 的 Workshop 上传（或游戏内 Mod 上传入口），内容目录指向 `PwABridge` 文件夹；预览图自备。上传前可在本机 `mods\PwABridge` 再启动一次确认。
