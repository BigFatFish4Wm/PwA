# PwA 1.3.2 发布说明

发布日期：2026-10-31

## 这版改什么

为发布到 npm / Coopanion 扩展市场做打包整理（玩法与 Mod 代码不变）：

- World 的 `package.json` 补齐 npm 元数据：`repository` / `homepage` / `bugs` / `keywords` / `files` / `os: win32`；
- 声明市场标签：`cortico.tags = ["game", "external-setup", "experimental"]`；
- npm 包只带 7 个文件（`index.js`、`dist/webui.js`、`ENV_PROMPT.md`、`README.md`、`LICENSE`、`THIRD_PARTY_NOTICES.md`、`package.json`），26.6 kB；
- README 重写成面向安装者的版本（依赖、安装、工具、配置、联机、隐私、许可）；
- 版本号统一到 1.3.2（Mod / World / `WORLD_BUILD`）。

## 安装

- Mod：`PwABridge-1.3.2.zip` → `mods\PwABridge\`；
- World：Coopanion 扩展页搜 `cortico-world-pwa`，或 `npm i cortico-world-pwa` 后从本机目录安装。
