# PwA 1.2.0 发布说明

发布日期：2026-10-31

## 这版加什么

**三人房**：一个你、一个汐（本机 client）、一个远程玩家（另一台机器，装同一个 Mod）。

默认仍然只听 `127.0.0.1`，需要显式开启：

| 环境变量 | 作用 |
|---|---|
| `PWA_COOP_BIND` | 中继绑定地址，默认 `127.0.0.1`；开远程设 `0.0.0.0` |
| `PWA_COOP_TOKEN` | 共享口令；设了之后，注册没带/带错口令一律拒绝（`token mismatch`） |
| `PWA_COOP_INDEX` | client 下标：汐用 1，远程用 2（再来一个用 3） |

一键启动（主机，本地只开汐一个 client）：

```powershell
powershell -ExecutionPolicy Bypass -File tools\start-coop.ps1 -Bind 0.0.0.0 -Token '<口令>' -Clients 1
```

远程玩家：

```bat
set PWA_COOP=client
set PWA_COOP_INDEX=2
set PWA_COOP_ENDPOINT=<主机IP>:33772
set PWA_COOP_TOKEN=<口令>
SlayTheSpire2.exe --force-steam off --clientId 1002 -fastmp join
```

World 的 `sts2_coop_start` 也支持 `clients`（1–3）、`bind`、`token` 三个参数，配置键是
`coopClients` / `coopBind` / `coopToken`。

## 实测（本机三窗口，1.2.0）

- host 8091、client1 8092、client2 8093 同时到「角色选择」；
- 中继日志：`client-1 index=1`、`client-2 index=2` 先后注册；
- 三人各自启程后，三个窗口的 `run.players` 都是 **3**；
- 中继监听 `0.0.0.0:33772`；
- 不带口令的注册被拒绝：`Broker registration rejected: token mismatch.`

## 已知限制

- 远程玩家必须装 PwA Mod（broker 传输）；原版客户端直接进需要 ENet↔broker 桥，本版没做；
- broker 是明文 TCP，公网请走 Tailscale/ZeroTier 或 SSH 隧道；
- 异地真实延迟未实测（本机用两个 client 模拟，其中一个走中继的局域网地址逻辑）；
- 三个以上（4 人）协议上支持（index 0–3），未实测。

## 安装

- Mod：`PwABridge-1.2.0.zip` → `mods\PwABridge\`（所有玩家都要装同一个版本）；
- World：`cortico-world-pwa-1.2.0.zip` → Coopanion 扩展目录，重启 Coopanion。
