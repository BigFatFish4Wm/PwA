# PwA 1.0.0 发布说明

发布日期：2026-10-30

## 这是什么

《杀戮尖塔 2》的本机桥接：**Mod**（`PwABridge`）把一个游戏窗口的状态与原子动作暴露成本机
MCP / HTTP；**World**（`cortico-world-pwa`）把它们变成 Coopanion 桌宠「汐」可调用的工具。
只提供动作，不做决策；支持单人，也支持本机双窗口联机。

## 1.0.0 包含

### Mod（PwABridge）

- 状态：`/state` 全量局面（含选牌/选遗物/卡牌包界面、奖励、商店、营火、宝箱、事件、地图、结算页）
- 动作：34+ 原子动作，覆盖出牌、药水、地图、事件、宝箱、奖励、商店、营火、选牌、继续/跳过、结算退出
- 稳定性：
  - 所有游戏读取都回到 Godot 主线程（HTTP 线程只读脉冲缓存，不会冻结游戏）
  - 动作回执等局面稳定（换回合会等到真正可出牌，最多 2.5s）
  - 敌人提供 `combat_id`，动作支持 `target_id`（目标死亡后不会串位）
  - 选牌超出 `max` 会拒绝（`selection_full`），避免卡在超选界面
  - 重复动作在局面未变时会被拒绝（`duplicate`）；可重复事件选项需要 `again:true`
- 联机（**broker 传输**，替代官方 `-fastmp` 回环）：
  - host 窗口进程内跑 TCP 中继（默认 127.0.0.1:33772），client 连它
  - 替换游戏 v0.111 的 `NetHost` / `NetClient` 传输；握手、消息总线仍由游戏自己完成
  - 修复过：Harmony prefix 返回值写反导致 `_netHost` 被换回 ENetHost、主线程不抽包、握手首包不发、`IsConnected` 语义、离线模式本地玩家 id 与传输层 NetId 不一致

### World（cortico-world-pwa）

- 工具：`sts2_view` / `sts2_act` / `sts2_plan` / `sts2_wait` / `sts2_diag`
- 联机房间：`sts2_coop_start` / `sts2_coop_stop` / `sts2_coop_state` + World 面板「联机房间」按钮
- 自动推进（省模型调用）：收金币/药水、继续、开箱、唯一地图节点、无牌可出时结束回合（`auto` / `autoEndTurn` 可关）
- 超长回执自动瘦身且保持合法 JSON；角色/端口自动发现并优先选 client（8092）

## 已验证

- 单机：完整一局（事件、地图、战斗、奖励、商店、营火、宝箱、选牌、结算页、死亡后退出）逐项修到可用
- 联机：两个窗口从第 1 层打到 **第 2 幕第 20 层**（含 Boss 与换幕）；共享状态（层/幕/回合/阵营/敌人血量）一致，client 出牌 host 立刻可见；中继累计 2.5 万条转发、0 丢弃；一致性采样中瞬时差异 ≤ 2.3 秒（演出同步），无持续漂移

## 已知限制

- 只针对游戏 **v0.111.0**（Windows/Steam）；版本更新可能破坏钩子
- 联机只验证了 1 host + 1 client；3–4 个客户端协议上支持但未测
- 两个窗口都用键鼠，没有手柄分配
- 瞬时不同步（≤ 2–3 秒）在双方同时出牌的演出期间可能出现，之后收敛
- 桌宠桥（coopanion-connector-dsh）默认会把工具调用推给桌宠，用 `tools/patch-coopanion-connector.mjs` 静音

## 安装（摘要）

见 [使用教程](使用教程.md)。最短路径：

1. 解压 `PwABridge-1.0.0.zip`，把 `PwABridge` 目录放进 `…\Slay the Spire 2\mods\`；
2. 解压 `cortico-world-pwa-1.0.0.zip` 到固定目录，在 Coopanion 扩展里启用，重启 Coopanion；
3. 开游戏 → 助手调 `sts2_view`。
