# PwA 1.4.1 发布说明

发布日期：2026-10-31

## 这版改什么

发布前的清理与可用性修正（玩法不变）：

- **隐私/敏感信息清理**：README/LICENSE/ENV_PROMPT 里不再带个人昵称；游戏目录不再写死本机路径，改为「配置 > `PWA_GAME_ROOT` > Steam 注册表/库目录 > 默认路径」自动查找；
- **验证范围写清楚**：单机完整一局、本机双人、本机三人、带工坊 Mod 启动都已确认；**远程真人玩家未验证**——目前确实缺少真实的第三方玩家来测试，只验证了 TCP 连通、口令校验和中继注册；
- **运行成本**：README 标注 agent 用 DeepSeek v4.1 flash 1017 时约 **¥3/小时**（按实际调用量浮动）；
- npm 元数据补充成本说明，`files` 白名单保持 7 个文件。

## 发布产物

- npm：`cortico-world-pwa@1.4.1`（发布后进入 npm 的 staged 审核，见下）；
- GitHub Release：`PwABridge-1.4.1.zip` / `cortico-world-pwa-1.4.1.zip`；
- Steam 上传用：`release/PwABridge-1.4.1-steam.zip`（内部只有 `PwABridge/` 文件夹）和解压目录 `release/PwABridge-1.4.1-steam/PwABridge/`。

## npm 状态

`npm publish` 已被接受，但 npm 对新包/首次发布做了 **staged publishing**：registry 先出现 `0.0.0-stage` 占位版本，说明真实版本在审核队列中，审核通过后才会替换。需要等 npm 处理或到 npmjs.com 该包页面确认。
