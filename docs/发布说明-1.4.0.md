# PwA 1.4.0 发布说明

发布日期：2026-10-31

## 这版加什么

**联机启动时可以带上已下载的创意工坊 Mod。**

### 背景

PwA 启动游戏用 `--force-steam off`（不初始化 Steam），双窗口稳定、不用登录；代价是 **Steam 创意工坊的 Mod 不会加载**，游戏只读 `mods\` 目录。

### 做法

启动前把创意工坊里已下载的 Mod 以 **junction** 链进 `mods\`，游戏就会当普通本地 Mod 加载：

- Coopanion 面板：勾选「带上创意工坊 Mod」；
- 命令行：`tools\start-coop.ps1 -WithWorkshopMods`，可加 `-WorkshopOnly id1,id2`；
- 单独工具：`tools\sync-workshop-mods.ps1`（`-Only` 过滤、`-WhatIf` 预览、`-Remove` 只删本工具建的链接）；
- World 配置：`coopWithWorkshopMods` / `coopWorkshopOnly`；工具参数：`withWorkshopMods` / `workshopOnly`。

### 实测

- 全量链接：`mods\` 里多出 16 个 junction，游戏日志 `Loaded 17 mods (17 total)`；
- 只链 `silentSkin`：`Loaded 2 mods`（PwA + 皮肤）；
- `-Remove` 后 `mods\` 恢复成只剩 `PwABridge`；
- 测试用的链接已清理，当前游戏目录保持原样。

### 注意

- **联机双方必须装同一套 Mod**，否则 hash/同步对不上；
- 玩法类 Mod 会改存档/profile，第一次开前建议备份；
- 工坊更新后目录可能变，再点一次开始（或跑一次脚本）会重指链接；
- 不想带就保持默认关闭（`coopWithWorkshopMods=false`）。

## 升级

- Mod 与 World 都升到 **1.4.0**；
- 面板/World 改动需重启 Coopanion；
- npm 发布仍在等带「Bypass 2FA」的 token（1.3.2 已打包好）。
