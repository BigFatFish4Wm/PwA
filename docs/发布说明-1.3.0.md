# PwA 1.3.0 发布说明

发布日期：2026-10-31

## 这版改什么

联机面板按「角色」重做，并回答一个资源问题：**远程玩家不启动本地窗口，开几个远程位都不占本机资源**。

### 面板语义

| 位置 | 谁 | 本机进程 |
|---|---|---|
| host（8091） | 你，固定本机 | 1 个 |
| client（8092） | 汐，固定本机 | 1 个 |
| 远程位 0–2 | 别人，在各自电脑上开窗口 | **0 个** |

- 远程位只影响：是否生成口令、生成什么启动命令、面板显示「已连 n/2」；
- 想在本机测试三人局，才把 `localClients` 设为 2（多开一个本机窗口）；
- 面板新增：远程位选择、口令输入/随机、**复制远程命令**、名额占用显示。

### 其它

- 主机 `/health` 增加 `coop_peers`（当前已注册的窗口下标，如 `[0,1,2]`），面板据此显示远程位占用；
- `sts2_coop_start` 参数改为 `localClients` / `remoteSlots` / `bind` / `token`；`remoteSlots > 0` 且没给口令时自动生成；
- 绑定地址默认仍是 `127.0.0.1`（配内网穿透）；局域网直连把它设成 `0.0.0.0`，命令里会自动带本机局域网 IP。

## 实测

- `localClients=1, remoteSlots=2`：只拉起 host + 汐两个窗口；自动生成口令；`remote.command` 给出 `<隧道地址>:33772` 的完整启动命令；
- `coop_peers` 返回 `[0,1]`（host + 汐），远程位显示 `已连 0/2`；
- 关闭联机后两个窗口都被回收。

## 升级

- Mod 与 World 都升到 **1.3.0**；
- 面板/World 代码不热加载，**重启 Coopanion** 后生效；
- 远程玩家仍然需要装同一个 Mod（1.3.0），但他那边只需开 1 个窗口。
