# PwA 使用教程（v1.0.0）

从零开始：装 Mod → 装 World → 单人开玩 → 本机双窗口联机 → 排错。

---

## 0. 你需要什么

| 依赖 | 说明 |
|---|---|
| 《杀戮尖塔 2》 | Steam 版，Windows，**v0.111.0** |
| Coopanion | 桌面版（含「汐」桌宠） |
| .NET 9 SDK | 只有自己编译 Mod 才需要；用发布包不需要 |

发布包两个 zip：

- `PwABridge-1.0.0.zip`：Mod（DLL + 清单 + 安装/联机脚本）
- `cortico-world-pwa-1.0.0.zip`：World（Coopanion 扩展）

---

## 1. 安装 Mod

1. 找到游戏目录（Steam → 库 → 右键游戏 → 管理 → 浏览本地文件），通常是：

   ```
   D:\Programs\Steam\steamapps\common\Slay the Spire 2
   ```

2. 在 `mods` 下建一个目录，名字必须是 **`PwABridge`**：

   ```
   …\Slay the Spire 2\mods\PwABridge\
   ```

3. 把发布包里的两个文件放进去：

   ```
   …\mods\PwABridge\PwABridge.dll
   …\mods\PwABridge\PwABridge.json
   ```

   > 注意：`PwABridge.json` 是清单（发布包里叫 `mod_manifest.json`，复制时改名为 `PwABridge.json`）。
   > **这个目录里只能有一份 json**，多一份会被当成两个 mod 重复加载。

4. 启动游戏，日志里应出现：

   ```
   [PwA] 初始化 mod 1.0.0（游戏 0.111.0）
   [PwA] 就绪：http://127.0.0.1:8090/mcp （MCP）/ /state （REST）
   ```

   游戏日志：`%APPDATA%\SlayTheSpire2\logs\godot.log`。

5. 用浏览器或 curl 验证：

   ```
   curl http://127.0.0.1:8090/health
   ```

   返回 `{"service":"pwa","status":"ready",...}` 就成功了。

> 端口规则：单人 **8090**、联机 host **8091**、联机 client **8092**；被占用时顺延。
> 端点文件写在 `%LOCALAPPDATA%\PwA\endpoints\<pid>.json`，World 靠它发现窗口。

---

## 2. 安装 World

两种方式任选：

### 方式 A：扩展页安装（推荐）

1. 把 `cortico-world-pwa-1.0.0.zip` 解压到一个固定目录，例如
   `D:\workspace\cortico-world-pwa`；
2. Coopanion → 扩展页 → 从本地目录安装 / 添加链接；
   最终要出现在：

   ```
   …\coopanion\data\extensions\node_modules\cortico-world-pwa
   ```

   如果是链接（junction），`cortico-world-pwa` 目录里的 `package.json` 必须能被读到。

### 方式 B：直接建链接

```powershell
powershell -ExecutionPolicy Bypass -File tools\link-world.ps1
```

3. 在 Coopanion 设置里启用 `worlds.pwa`：

   ```json
   "worlds": {
     "pwa": {
       "enabled": true,
       "auto": true,
       "autoEndTurn": true
     }
   }
   ```

4. **完全退出 Coopanion 再打开**（World 代码不热加载）。

5. 验证 World 已挂载：Coopanion 的 World 面板里出现「杀戮尖塔 2（PwA）」，或让助手调
   `sts2_diag`，应返回 `connected: true`、`base: http://127.0.0.1:8090`（单人）。

## 3. 单人开玩

1. 游戏里正常开一局（或读档）；
2. 对助手说：「看下局面」「打这张牌」「结束回合」「去左边的地图节点」；
3. 助手背后调用的是：

   | 工具 | 用途 |
   |---|---|
   | `sts2_view` | 看局面（`full:true` 一定是全量） |
   | `sts2_act` | 做一个动作 |
   | `sts2_plan` | 连做几步（遇到选牌/未落定会停下） |
   | `sts2_wait` | 等状态变化（例如等敌人回合结束） |
   | `sts2_diag` | 连接诊断 |

4. 你随时可以自己在游戏窗口里操作，助手不会抢。

常用提示词示例：

- 「先看局面再决定，出牌前确认能量和目标」
- 「这回合尽量打满，然后结束回合」
- 「奖励先拿金币和药水，卡牌留给我选」
- 「到地图了告诉我有哪些节点」

## 4. 本机双窗口联机

### 一键开房

三选一：

1. **面板**：Coopanion → World 面板「联机房间」→「开始联机」；
2. **指令**：让助手调 `sts2_coop_start`；
3. **脚本**：

   ```powershell
   powershell -ExecutionPolicy Bypass -File tools\start-coop.ps1
   ```

开起来后：

| 窗口 | 谁玩 | 端口 |
|---|---|---|
| host（先起） | 你 | 8091 |
| client（后起） | 助手（汐） | 8092 |

World 会自动连 client 窗口；host 不需要被接管。

### 开始一局

1. 两个窗口都会到「角色选择」；
2. 你选角色 → 启程；
3. 汐在她的窗口选角色 → `sts2_act {"action":"embark"}`（或你让她点）；
4. 两边进游戏后，各玩各的角色，同房间/同战斗是共享的。

### 注意

- 两个窗口都必须装同一个 Mod（同一个 `mods\PwABridge`）；
- 两个窗口都是键鼠，**点哪个窗口哪个响应**；
- 关闭：面板「关闭联机」或 `sts2_coop_stop`，只会关 8091/8092 这两个窗口；
- 机制细节：[PwA-联机.md](PwA-联机.md)。

## 5. 常用配置

World 设置（`worlds.pwa.*`）：

| 键 | 默认 | 说明 |
|---|---|---|
| `enabled` | false | 是否启用 |
| `auto` | true | 自动收金币/药水、继续、开箱、唯一地图/弹窗 |
| `autoEndTurn` | true | 无牌可出时自动结束回合（只在 `sts2_view` 里） |
| `waitTurnSeconds` | 8 | 结束回合后等新回合的上限 |
| `pollSeconds` | 4 | 事件轮询间隔（提醒「轮到你了」） |
| `baseUrl` | 空 | 指定连接地址；留空自动发现并优先选 client |
| `coopGameRoot` | Steam 默认路径 | 一键联机用的游戏目录 |
| `coopBrokerPort` | 33772 | 联机中继端口 |
| `coopWithClient` | true | 一键开房时是否也拉起 client |

Mod 环境变量：`PWA_ENABLED=0` 可只加载不启动服务；`PWA_PORT` 指定端口。

## 6. 排错

| 现象 | 怎么办 |
|---|---|
| `health` 连不上 | 确认游戏窗口还在、日志里有 `[PwA] 就绪`；端口可能顺延，看日志里的实际端口 |
| 助手说没找到窗口 | 看 `%LOCALAPPDATA%\PwA\endpoints\` 有没有当前 pid 的 json；`sts2_diag` 看 windows |
| 画面 `UNKNOWN` | 转场/读档中，等 1–2 秒；或 `sts2_view full=true` |
| 联机握手超时 | 两个窗口都要有 Mod；先起 host 再起 client；看 `%LOCALAPPDATA%\PwA\coop-<pid>.log` |
| 联机中一边卡住 | 先看两边 `sts2_view full=true` 的 `screen`；再看 `coop-*.log` 里中继转发是否还在 |
| 桌宠被工具调用刷屏 | `node tools\patch-coopanion-connector.mjs`（仓库工具，见 README） |

日志位置：

- 游戏/Mod：`%APPDATA%\SlayTheSpire2\logs\godot.log`（多开会轮转成 `godot<时间>.log`）
- 联机：`%LOCALAPPDATA%\PwA\coop-<pid>.log`
- 端点：`%LOCALAPPDATA%\PwA\endpoints\`

---

## 7. 卸载

1. 关游戏，删掉 `…\Slay the Spire 2\mods\PwABridge\`；
2. Coopanion 停用 `worlds.pwa` 并移除扩展目录；
3. 可选：删 `%LOCALAPPDATA%\PwA\`（端点文件与联机日志）。

---

## 8. 自己编译（可选）

```powershell
cd PwA
dotnet build -c Release          # 需要 sts2.dll / 0Harmony.dll / GodotSharp.dll，见 local.props
powershell -ExecutionPolicy Bypass -File ..\tools\install-mod.ps1
```

打包发布产物：

```powershell
powershell -ExecutionPolicy Bypass -File tools\pack-release.ps1
```
