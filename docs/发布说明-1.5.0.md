# PwA 1.5.0 发布说明

发布日期：2026-10-31

## 这版修什么

**Steam 工坊订阅用户也能用联机/agent 了。**

Steam 工坊的 Mod 不是“云端运行”：订阅后 Steam 把它下载到本机
`steamapps\workshop\content\2868840\<id>\`，游戏从本地加载，PwA 的 HTTP 服务仍然只监听 `127.0.0.1`。

问题在启动方式：联机用 `--force-steam off`（双窗口稳定、不用登录），此时游戏**不会挂载工坊目录**，只订阅工坊的 `PwABridge` 不会被加载。

### 修法

- World 的联机启动会先检查 `mods\PwABridge`：不存在时，从工坊目录里找到 `PwABridge` 并 **junction** 进 `mods\`；找不到才报错；
- `start-coop.ps1` 同理：启动前自动跑 `sync-workshop-mods.ps1 -Only PwABridge`；
- 工坊同步脚本不再无条件跳过 `PwABridge`，只在 `mods\PwABridge` 已存在时跳过（避免重复）。

### 安装方式对照

| 安装 | 正常启动（Steam 开） | 联机启动（Steam off） |
|---|---|---|
| `mods\PwABridge`（GitHub zip） | ✅ | ✅ |
| 仅工坊订阅 | ✅ | ✅（1.5.0 起自动链进 mods） |
