# PwA 1.1.0 发布说明

发布日期：2026-10-31

## 这版修什么

汐反馈：「界面已经等你按了，但没有推送」——开战第一个回合、敌人回合结束轮到我、出牌后弹选牌、结束回合真正翻到我、战斗奖励、奖励选牌、事件继续、地图投票、宝箱、营火，全都收不到提醒。

### 根因（两个层面叠在一起）

1. **Mod 侧事件太薄**：`StatePulse` 只拿 `screen / turn / choice / turn_started / floor` 这个极简快照做去重，同一个画面里的「轮到你选 / 可以继续」变化不会改变 key，于是不产生事件；
2. **World 侧只翻译两类**：只把 `turn_started`、`player_choice_required` 转成消息，其余（`screen_changed`）直接丢掉；
3. 附带两个坑：
   - 事件序号在游戏重启后会归零，World 用 `Math.max` 保留旧游标，重启后**永远收不到新事件**；
   - 结算页节点隐藏后仍被当成 `GAME_OVER`，导致「继续」卡住。

### 修法

**Mod（1.1.0）**

- 新增 `BuildAttention()`：给出「现在是不是在等你操作」的粗粒度状态，kind 覆盖：
  `my_turn`、`selection`（含选牌/选遗物/卡牌包）、`reward`、`reward_card`、`reward_proceed`、
  `event_option`、`event_proceed`、`map`、`map_travel`、`chest_open`、`chest_relic`、`chest_proceed`、
  `rest_option`、`rest_proceed`、`modal`、`character_select`、`game_over`；
- 只有 kind/细节变化时才写 `attention` 事件，同一局面不会反复提醒；
- `turn_started` 现在要求真正进入 `Play` 阶段（回合开始前的遗物/状态结算不再误报「轮到你了」）；
- `/health` 增加 `events_seq`，World 用它和游戏进程对齐事件游标（重启自动复位）。

**World（1.1.0）**

- 把 `attention` 翻成中文提醒（见下）；
- 收到 `attention` 的那一批里忽略旧的 `turn_started`/`player_choice_required`，避免重复；
- 相同提醒 6 秒内去重；
- 事件游标回退（游戏重启）时自动重置，不再「永久静默」。

## 实测（1.1.0，双窗口/单人通用）

一次完整流程里 World 实际推送：

```
等你选角色。
事件等你选选项：涅奥。
事件结束了，等你按继续（proceed）。
地图等你选路/投票。
地图已经出发。
轮到你了（第 1 回合）…（每回合一条）
战斗结束，有奖励可以领：金币/药水/卡牌。
战斗奖励：等你挑一张牌（或跳过）。
奖励领完了，可以继续。
地图等你选路/投票。
事件等你选选项：这个还是那个？。
事件结束了，等你按继续（proceed）。
结算页等你操作。
```

Mod 侧事件环也验证过 `selection`（选牌界面）与 `chest_*`/`rest_*` 的 kind 能正常产生。

## 兼容性

- 游戏 v0.111.0；
- **Mod 和 World 要一起升级到 1.1.0**（World 靠新的 `attention` 事件；旧 Mod 仍兼容旧事件，但不会有新提醒）；
- 联机、单人行为不变。

## 安装

同 1.0.0：`PwABridge-1.1.0.zip` 解压到 `mods\PwABridge\`；`cortico-world-pwa-1.1.0.zip` 装到 Coopanion 扩展目录后重启 Coopanion。
